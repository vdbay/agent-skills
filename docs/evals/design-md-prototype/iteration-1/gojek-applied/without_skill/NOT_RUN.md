# Baseline not run

This applied evaluation used a real-brand production task. A no-skill baseline would require a second full research + DESIGN.md + two-page build, and it was not run. The with-skill run is real and independently judged; the missing baseline is a limitation, not a claimed result.

To complete the controlled comparison, run the same prompt with no skill path in a fresh context, save it under `without_skill/outputs/`, and grade it with the same rubric. Do not reuse the with-skill artifacts or conversation.
