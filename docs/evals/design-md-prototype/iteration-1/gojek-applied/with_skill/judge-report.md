## What works

- **The central idea is real, not decoration.** The route line connects the hero day panel, the four moment cards, the system view, the corporate process, and the closing CTA. The same 2px line and circular nodes carry both the consumer and corporate stories; the day/register switch is the proof rather than a claim (`index.html:2700–2790`).
- **The two-register model is coherent.** One token core, one green, one type family, one 4px unit, one focus treatment; the consumer and corporate registers change density, accent proportion, type scale, tone, and motion only (`DESIGN.md:473–480`). There is no second primary or second brand.
- **The token core is well-formed and exportable.** `DESIGN.md` has 58 colors, 15 typography scales, 8 radii, 12 spacing tokens, and 53 components. Official lint is clean, the CSS export contains all expected properties, and every `{reference}` resolves.
- **The contrast work is unusually honest.** The brand/product green split, the failed `#269A31` hover behind white text, the failed `#00880D` on `#EAFFEA`, the failed `#8F6F14` warning text, the `#BDBDBD` control-boundary failure, and the 2.19:1 blue focus halo are all documented and corrected with measured roles (`DESIGN.md:492–524`). My independent calculations match the table: ink-on-white 16.90:1, muted 4.81:1, product green 4.64:1, ink-on-brand 5.44:1, dark body 17.07:1, dark accent 6.00:1, dark primary text 5.48:1.
- **The dark closing CTA focus ring passes the specific check.** The 3px `:focus-visible` outline on `.cta-panel` is `#1C1D1D`; on the `#00AA13` panel it measures **5.44:1**, above 3:1. The focus ring is not white/light. The 5px `box-shadow` outside it is `#F5F5F2` and measures **2.84:1**; that light halo should be removed or darkened, but it is not the ring that carries the requirement. This is the distinction I applied.
- **The ecosystem is genuinely usable.** Primary flow is keyboard-operable, mobile nav and TOC are disclosures with Escape and focus return, the theme toggle persists through `localStorage` (and still works when storage is blocked), reduced motion is honored, and the pages work from `file://` with no external requests.
- **The evidence packet is real.** The 20 screenshots are current full-page captures for every tested page/width/theme cell; `browser-matrix.json` matches the matrix; the two Lighthouse reports are 100/100; the lint/export/static files agree with reproducible commands. The 429 and the unavailable Tech blog are disclosed rather than hidden.
- **Rights and brand safety are clean.** No copied logo, photograph, testimonial, or font binary; the route mark is original; the wordmark is typographic; the unofficial disclaimer is visible on both pages and in the footer. Gojek service names are context only.

## Required fixes

1. **Dark closing CTA — remove the light halo and strengthen the light button boundary.** In `index.html:226–229`, `.cta-panel :focus-visible` sets `outline-color:#1C1D1D` (good, 5.44:1) but keeps `box-shadow: 0 0 0 5px #F5F5F2`; that 5px ring is **2.84:1** on `#00AA13`. The `button-ink` fill in dark is also `#F5F5F2` (`index.html:126`, `670–673`, `2097`) and its boundary on the green panel is **2.84:1**. Use an ink border/ring, a dark halo, or a `#FFFFFF` fill (3.11:1) for the light CTA button, and remove or darken the white halo. This is the main AA gap.
2. **Align the live component gallery to its own component tokens.** `design-md.html` alerts use 12px text, 12px/14px padding, and `--radius-md` (12px) while `DESIGN.md` defines `body-sm` 14px, 16px padding, and `rounded.lg` 16px; the badge uses 11px/700/5×9px while `badge` defines `label-sm` 12px/600/6px; the toast uses 12px/12px/`--radius-md` while `toast` defines `body-sm` 14px/16px/`rounded.lg`; button labels are 700 while `label-md` is 600. Either align the live classes to the tokens or label the gallery as illustrative rather than token-exact. This is the largest showcase/craft inconsistency.
3. **Correct the README color count.** `README.md:22` says “58 colors (38 core + 20 dark role extensions)”. The file has 31 base colors and 27 `*-dark` colors. Keep the total 58, but state the actual split (or derive it from the lint summary).
4. **Tokenise or map the dark `on-brand` role.** `index.html:104–105` sets `--color-on-brand:#08210D` in dark, but `DESIGN.md` has no `on-brand-dark`; the nearest token is `on-primary-dark:#08210D` (`DESIGN.md:43`). The spec pair grid shows `on-brand` only as `#1C1D1D` (`design-md.html:2522`). Add `on-brand-dark` or document the alias/mapping.
5. **Document the off-scale type and spacing values.** The 15-token scale is 72/48/40/36/32/28/24/18/16/14/12px, but the prototype/spec chrome uses 52/42/34/26/20/19/15/13/11/10px and gaps such as 18/14/22px. The hero clamp is documented; the rest is not. Either map these to the scale or add a short “campaign/editorial extension” paragraph with the intended values. This is the main craft deduction.
6. **Make the focus prose theme-aware.** `design-md.html:2812–2813` and `DESIGN.md:488/582` say the focus ring is 3px ink. In dark, `--color-focus` is `#F5F5F2` and the ring is light (`index.html:124`). State the light/dark pair and where the ring sits on the surface, so the token contract matches what a keyboard user sees.
7. **Change the judge card from “Reviewed” to “Pending” until a report exists, or make the link conditional.** `design-md.html:3096–3101` displays a “Reviewed” status and “A fresh-context judge reviewed…” before `evidence/judge/judge-report.md` existed. After this report it is true, but the artifact should not claim a review ahead of the file. Keep the report out of future blind packets as the README says.
8. **Minor:** at 390px the consumer/system segmented control wraps “Dari sisi pengguna” onto two lines while the other option stays on one (`index.html`: segmented-control CSS around 1043, markup 2715–2719); reduce the label/padding or stack the control. The panel link `#layanan-goride` (`index.html:2772`) targets its own service card, which is a circular jump; point it at the service section/card with copy that matches. The TOC toggle’s `aria-label="Open section navigation"` (`design-md.html:2245`) should become a stable “Section navigation” label or toggle to “Close” when expanded.
