## Conflicts and resolutions

| Conflict | Evidence | Resolution |
| --- | --- | --- |
| Brand green vs product green | gojek.design names #00AA13; gojek.com UI uses #00880D as its interactive accent | Keep both. `colors.brand` is #00AA13 for large fields/display; `colors.primary` is #00880D for controls and normal-size text. Documented in Colors. |
| Official hover #269A31 vs white label contrast | White 14px on #269A31 = **3.65:1**, below AA | Do not use #269A31 behind text; keep it as an official source value only. Use the official active #00680A as the text-safe hover (7.04:1). Documented in Components. |
| Official border #BDBDBD vs control boundary | #BDBDBD on white = **1.88:1**, below 3:1 | #BDBDBD is a decorative divider only. `border-strong` #727272 (4.81:1) defines inputs and secondary controls. |
| Success green on soft green | #00880D on #EAFFEA = **4.42:1**, just below 4.5 | Use `success` #00680A (6.70:1) for text on the tint; the fill remains the product green. |
| Warning text on soft yellow | Official #8F6F14 on #FFF8E7 = **4.46:1**, just below 4.5 | Use `warning-text` #7A5D0E (5.83:1) on the tint. Official #8F6F14 remains valid on white at 4.72:1. |
| Official focus blue vs white | #86AFFF on white = **2.19:1**, below 3:1 | Use a 3px ink focus ring plus the official blue as a 5px outer halo. The ring carries the contrast requirement. |
| Brand-site RGB/CMYK/Pantone values vs hex | gojek.design shows “RGB 19, 0, 50 / PANTONE 276” next to #00AA13, which is internally inconsistent | Use the hex #00AA13 only. The ancillary print values are not repeated or treated as authoritative. |
| Current site display line-height vs Asphalt scale | gojek.com uses 1.618 on 40px display tokens; Asphalt describes a 1.3 scale and a 4px line-height grid | Preserve current `display-2xl` at 1.618; add tighter `brand-hero`/`brand-display` line-heights as a documented campaign extension. |
| gojek.io corporate expression unavailable | HTTP 429 on 2026-11-16 | Build the corporate register from first-party GoCorp/product facts, Asphalt, and gojek.design. Do not invent gojek.io copy or architecture. Record the gap. |
| Gojek Tech blog unavailable | Ghost private portal, not public articles | No blog facts or quotes used. The engineering register is supported by official product/platform evidence and OSS metadata, not by invented culture claims. |
| Proprietary typeface vs standalone HTML | Maison Neue and Maison Neue Extended are proprietary | Name them in DESIGN.md; do not download or redistribute. Use a documented Helvetica/Arial fallback in HTML and label it in the showcase. |

## Assumptions

1. **Concept status.** The artifacts are an unofficial concept. The wordmark is typographic, the route mark is original geometry, and there is no affiliation or endorsement.
2. **Register languages.** Consumer copy is Bahasa Indonesia; corporate/technology copy is English. This is a deliberate register delta, not a claim that Gojek uses only one language in each context.
3. **Current web UI as evidence.** The gojek.com inline CSS is treated as representative of the current consumer web UI, not the native iOS/Android app. Native tokens may differ.
4. **Dark theme is an original extension.** Asphalt documents light and dark themes, but the published images did not expose usable dark hex values. The dark surfaces, borders, and semantic text roles are derived and documented; they are not claimed as official dark tokens.
5. **Motion timings.** The four easing curves and motion principles come from the official motion page [S14]. The 0.8s showcase comparison and the interface timings (120/200/320ms) are system decisions for this concept, not official product timings.
6. **Sample day.** The four moments, times, routes, and system steps are fictional examples. They are labelled “Skenario contoh” and are not user data.
7. **Illustrative system view.** “Demand → Match → Move → Settle” is a simplified narrative for the corporate register, not a claim about Gojek’s internal architecture.
8. **Corporate evidence gap.** Because gojek.io returned 429, the corporate register leans on GoCorp, the official products page, and Asphalt. It does not claim to reproduce gojek.io’s layout or copy.
9. **Fonts.** No font binary is included. The pages use the operating system’s Helvetica/Arial fallback; Maison Neue is named for specification accuracy, not rendered from a licensed binary.
10. **Metrics.** No company metrics, awards, customer names, testimonials, or press quotes are used, even where official pages publish them, because they are unnecessary for the design argument and would require separate substantiation.

- **Logo:** No official logo asset, wordmark SVG, product logo, or favicon is copied. The wordmark is set in the fallback type; the small route mark is original CSS/SVG geometry. It is explicitly labelled a concept.
- **Photography and illustration:** None used. All visuals are CSS, HTML, or original inline SVG.
- **Testimonials and case studies:** None used. GoCorp testimonials were visible on the official page but were not copied.
- **Fonts:** Maison Neue and Maison Neue Extended are proprietary. No `.woff`, `.woff2`, `.ttf`, or `.otf` file is included. Fira Code is open-source (SIL OFL) but is also not shipped; the code stack falls back to a platform monospace.
- **CSS excerpt:** `evidence/source-css-extract.txt` is a short, attributed excerpt of factual token values from the public gojek.com page, retained for provenance. It is not presented as product source code.
- **Brand guideline PDF:** Retrieved (HTTP 200) but not redistributed and not parsed. No content from it is reproduced.
- **Gated content:** gojek.io’s 429 was not bypassed. The Gojek Tech blog’s private portal was not scraped. No login, paywall, or access control was circumvented.
- **Third-party sources:** Used only for discovery. No clone, fan site, or template marketplace is treated as brand truth.
